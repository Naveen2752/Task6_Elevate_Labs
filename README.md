# 🌐 Personal Portfolio Website (Flask)

A clean and simple **portfolio website** built using **Flask**, **HTML**, and **CSS**.
This project showcases your personal profile, projects, and includes a working **contact form**.
Perfect for internships, resumes, and GitHub portfolios.

---

## 🚀 Project Overview

This web app is a lightweight personal portfolio built with Flask.
It demonstrates:

* Flask routing
* Templating with HTML
* Static file handling (CSS)
* Form handling (Contact page)
* Clean and organized project structure

It’s ideal for anyone who wants to build and deploy their own portfolio website as a Python developer.

## ✨ Features

### ✔ **Home Page**

* Your name, description, and a hero section.

### ✔ **Projects Page**

* List of your completed projects (easily editable).

### ✔ **Contact Page**

* Fully functional contact form (POST request)
* Displays “Message Sent” confirmation
* Prints message details in the terminal (acts as backend processing)

### ✔ **Clean UI**

* Simple navigation bar
* Basic but neat CSS styling
* Easy to customize or theme

## 🔧 How to Run Locally

### **1. Clone the Repository**

```bash
git clone https://github.com/your-username/portfolio-flask.git
cd portfolio-flask
```

### **2. Install Dependencies**

```bash
pip install flask
```

### **3. Start the Server**

```bash
python app.py
```

### **4. Open in Browser**

```
http://127.0.0.1:5000/
```
